Add to list

One button. Click it on any product page and it copies a finished entry to your clipboard, ready to paste.

What it does

It reads what the shop publishes about the product, then shows you the fields so you can correct anything before copying. It runs as you, in your own browser, so shops that answer a script with a bot check answer this with the product.

Nothing is guessed. A field it could not read is left empty and marked in red.

Install: Chrome, Edge, Brave

  1. Show the bookmarks bar if it is hidden, with Command Shift B.
  2. Drag the button below onto it.

Add to list

Clicking it here does nothing. It has to sit on the bar and be clicked while you are on a product page.

Install: Arc, Safari, anything without a visible bar

Arc hides the bookmarks bar, so drag will not work. Add it by hand instead, using the address below as the bookmark's URL.

  1. Copy the address with the button under the box.
  2. Open the bookmark manager, Command Option B in Arc.
  3. Add a bookmark, name it anything, paste this as the address.

Or skip bookmarks entirely

Open the developer console on the product page with Command Option J, paste the code below and press return. Same result, nothing to install.

When it changes

A saved bookmark keeps the copy you saved. If the tool is updated, come back and drag or paste it again.
